# Between The Pages

## Description
I read a lot of books and i do have a physical book tracker but i need multiple to store what I want for each book. I wanted a space that could hold all my books together and 
never really run out of space so I made this app. An added bonus is that I can make it a lot more aesthetic with pictures and other stuff to make it pretty and I also wanted it
to look like an acutal bookshelf and since I know how to code, I thought why not build it myself. 
Rather than just storing books, this app also lets you visually place them on shelves (though you cant move them around... yet), customize them, and even decorate your shelf 
with your own little trinkets like plants or pictures. Each book has its own details like its title, author, number of pages, your random notes, start ratings and a custom 
cover image. The number of pages determines the width of the book while the genre determines the height of the book. You can also choose your own color for the spine that is 
shown on the shelves. 
I know there's apps like Goodreads and StoryGraph, but they dont really give a personal, creative feel for visuals. I wanted somethign that felt more like my space. 
This is one of my bigger projects, witht he firebase authorization, storing, and persisting so of course there were tons of bugs all along the way. Whenever I added a new 
feature, another one would break and I'd have to go bakc and fix that again. I did use a bit of AI for this but it was mostly as a last resort for debugging and to get all my 
features and coding structure organized so I could work on the code easily.
